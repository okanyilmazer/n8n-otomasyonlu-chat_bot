# n8n-otomasyonlu-chat_bot
Bu proje, kişisel gelişim amacıyla geliştirilmiştir. Amaç, site tasarımından ziyade n8n otomasyonu kullanılarak bir chatbot sisteminin nasıl kurulabileceğini göstermektir. Proje açık kaynak olarak paylaşılmıştır. Chatbot varsayılan olarak pasiftir; kendi API anahtarlarınızı eklediğinizde sistemin çalıştığını gözlemleyebilirsiniz.
