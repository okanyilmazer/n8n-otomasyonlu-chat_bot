A) n8n Tabanlı Chatbot Web Projesi
Bu proje, kişisel gelişim amacıyla geliştirilmiş bir web uygulamasıdır. Projenin temel amacı; bir web sitesi üzerinden n8n otomasyonu kullanılarak chatbot sistemlerinin nasıl kurulabileceğini ve entegre edilebileceğini göstermektir.
Tasarım veya görsel detaylar öncelik değildir; odak noktası otomasyon ve chatbot mantığıdır.

B) Projenin Amacı
Bu projede amaç:
n8n kullanarak bir chatbot akışı (workflow) oluşturulabileceğini göstermek
Bir web sitesinden gelen kullanıcı mesajlarının otomasyon üzerinden AI’a iletilmesi
API anahtarları kullanılarak sistemin esnek ve kişiselleştirilebilir hale getirilmesi
Açık kaynak bir örnek üzerinden öğrenme ve geliştirme imkânı sunmak

C) Önemli Bilgilendirme
Bu proje açık kaynak olarak paylaşılmıştır.
Bu nedenle:
Chatbot varsayılan olarak çalışmamaktadır
Herhangi bir API anahtarı projeye ekli değildir
Kendi API anahtarlarınızı eklemeden chatbot aktif olmaz
Gerekli API anahtarlarını ve n8n ayarlarını tamamladığınızda, sistemin sorunsuz şekilde çalıştığını görebilirsiniz.

D) Kullanılan Teknolojiler
HTML / CSS  – Ön yüz (Frontend)
n8n – Otomasyon ve chatbot akışları
